# Decision Log

Decision log that records key architecture decisions.

This log explains why things are as they are.

New engineers will find the log useful to build their understanding about the project. Existing engineers will find the log useful as a reminder on what was agreed.

There is no need for a [strict template](https://microsoft.github.io/code-with-engineering-playbook/design/design-reviews/decision-log/).

Only 2 things need to be documented:

1. Date of the decision.
2. Brief description of the decision, including context and the motivation behind the decision i.e. the "why".
