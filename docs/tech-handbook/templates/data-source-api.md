# Data Source - API

This template **must** be used across all pipelines that extract data from an API.

It is meant to make it easier for engineers to understand the behaviour of the API. This will lead to better understanding of the pipeline’s code and design decisions.

Copy paste this template and store it in the central location.

Add the link to the newly created document in the GitHub repo where pipeline’s code lives.

:::info
This template can be customised depending on the pipeline.
:::
